# stsdemo

A minimal demo of the [STS BBS](https://github.com/cewatkins/sts) system — a portable C reimplementation of the classic DOS-era BBS.

## Build

```sh
cd src
make
./stsdemo
```

## Usage

Run the demo binary from the `src/` directory:

```sh
./stsdemo
```

## Files

- `src/main.c` — Demo entry point
- `src/Makefile` — Build configuration
